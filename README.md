# 고1 1등급 학습 플래너

중3 겨울 ~ 고1 입학 직후까지 쓰는 **모바일 학습 플래너**입니다.
`index.html` 한 파일로 동작하고, 기록은 각자의 휴대폰 브라우저(localStorage)에 저장되면서 **구글 시트와 실시간으로 양방향 동기화**됩니다. 아이 폰과 엄마 폰에서 같은 주소를 열어 두기만 하면, 한쪽에서 체크·한마디를 바꾸면 몇 초 안에 다른 쪽 화면에 그대로 나타납니다.

## 기능

- **집중 타이머** — 20/30/40/60분 프리셋(기본 20분), 시작·일시정지·리셋, 원형 진행 표시, 완료 시 맑은 종소리(도-미-솔-도 두 번, Web Audio)·진동·축하 효과. 프리셋을 바꾸면 타이머 표시·남은 시간·리셋 기준이 그 분으로 바로 바뀝니다(실행 중이면 일시정지 후 새 시간으로 리셋).
  - **종료 알림음** — 시작 버튼을 누른 그 순간 오디오 잠금을 풀어 두어, 20~60분 뒤에도 휴대폰 브라우저(Android Chrome·iOS Safari)에서 소리가 막히지 않습니다. 지원 기기에서는 `navigator.vibrate` 진동도 함께 울립니다.
  - **🔔 소리 테스트 / 소리 켜짐·끔** — 타이머 카드에서 한 번 누르면 종료 차임벨을 바로 들어 볼 수 있어, 공부 시작 전 폰 볼륨·무음 모드를 확인할 수 있습니다. 소리 설정은 기기에 저장되고 기본값은 켜짐입니다.
  - 타이머가 도는 동안에는 화면 잠금을 막아(Wake Lock, 지원 기기) 화면이 꺼져 소리가 못 울리는 일을 줄입니다.
- **⏱ 계획 시간 vs 실제 시간 비교** — 할 일마다 목표 시간을 두고(추가·수정할 때 `20·30·40·60분` 칩 또는 직접 입력), 실제로 걸린 시간을 적으면 `목표 30분 → 실제 42분 (+12분)`처럼 차분한 배지로 비교해 보여 줍니다. 압박을 줄이려고 빨간 경고색 대신 베이지(초과)·민트(단축)·라벤더(딱 맞음)만 씁니다.
  - **연결할 할 일** — 타이머 카드에서 오늘 할 일을 고르면 그 항목의 목표 시간으로 타이머가 자동 설정됩니다. 시작하면 카운트다운이 돌고, 목표 시간에 닿으면 종소리·진동이 울린 뒤 **멈추지 않고 초과 시간(`+4:37`)을 계속 잽니다**. 다 끝나면 `✓ 완료 & 시간 기록` 한 번으로 실제 시간 저장 + 완료 체크가 됩니다.
  - **직접 체크했을 때** — 완료 체크한 항목에 `⏱ 실제 걸린 시간 적기`가 나타나 분을 적거나(`✎ 실제 시간 수정`) 지울 수 있습니다.
  - 저장 위치: 목표 시간은 항목의 `targetMin`(기존 `mins`와 같은 값), 실제 시간은 날짜별 기록 `days[YYYY-MM-DD].actual[항목ID]`. 기존 `g1-planner:v3`·`_동기화` JSON에 그대로 함께 저장되어 두 폰이 몇 초 안에 같은 값을 봅니다(구글 시트 `주간 체크표` B~I·J열 구조는 그대로).
- **📅 중3 전환기·고입 주요 일정 카드** — 요일 칩 바로 아래에 한 줄 요약(`오늘 · 대학 탐방 D-DAY` / `다음 · 11/18(수) 수능예비소집일 D-2`)이 늘 보이고, 누르면 11/16~1/8 전체 일정이 월별로 펼쳐집니다. 재량휴업(11/20)·수능(11/19)·일반고 원서접수(12/3~12/7)·졸업식(1/8)은 색으로 구분하고 지난 일정은 흐리게 표시합니다. 펼침 상태는 기기에 기억됩니다. (가정통신문 기준 일정이라 학교명·이름은 넣지 않습니다.)
- **이번 주 학원 일정 카드** — 화·목(수학 17:00~20:00), 토(수학 12:00~15:00 · 국어 15:00~17:00), 일(국어 12:00~14:00)을 요일별로 보여주고 오늘 줄을 강조합니다. **카드 제목 줄을 누르면 접히고(▾) 다시 누르면 펼쳐집니다(▴)**. 접혀 있어도 제목 옆에 `오늘은 학원 가는 날` 같은 한 줄 요약은 그대로 보이고, 접힘/펼침 상태는 기기에 기억되어 새로고침해도 그대로입니다.
- **주 이동 바 + 요일 선택 칩** — 요일 칩 위에 `◀ 지난주 · 11/16 ~ 11/22 (이번 주) · 다음주 ▶` 바가 있어 지난주·다음 주 기록을 언제든 넘겨 볼 수 있습니다. 다른 주로 가면 가운데가 `이번 주로` 버튼으로 바뀝니다.
- **요일 선택 칩 + 요일별 전체 보기** — 체크리스트 위에 `월 화 수 목 금 토 일` 칩과 `전체` 칩. **기본 선택은 항상 오늘 요일**이라 오늘 해야 할 공부만 보이고, 오늘 요일 칩에는 작은 `오늘` 표시가 붙습니다. 칩에는 지금 보고 있는 주의 날짜(11/16 등)가 함께 적혀 있습니다. `전체`를 누르면 그 주 7일 계획이 요일별로 한눈에 보이고 날짜와 그날 달성률이 함께 나옵니다.
  - 요일 칩은 **지금 보고 있는 주 안의 그 요일**을 엽니다. 그래서 일요일에 `토`를 누르면 어제(이번 주 토요일) 기록이 바로 열리고, 지난주로 넘어가서 `화`를 누르면 지난주 화요일이 열립니다(예전에는 '다음으로 오는 그 요일'로 넘어가 다음 주 빈 화면이 열렸습니다).
- **오늘의 학습 체크리스트 (요일별)** — 요일마다 그날 할 공부만 나오고, 체크는 그 날짜에 저장됩니다(다음 주 같은 요일에 다시).
  - **월 · 수**: ⏱️ 20분 타이머 · 📐 수학 복습·오답(40분) · 📖 국어 평일 20분 · 🔤 영어 문법·고1 모고 30분 · 🔬 과학 EBS 통합과학1 35분
  - **화 · 목**: ⏱️ 20분 타이머 · 📐 수학 (은쌤수학 5~8시 · 숙제/오답) · 📖 국어 평일 20분
  - **금**: ⏱️ 20분 타이머 · 📐 수학 복습·오답 · 📖 국어 평일 20분 · 🔤 영어 문법·고1 모고 30분
  - **토**: ⏱️ 20분 타이머 · 📐 수학 (은쌤수학 12~3시) · 📖 국어 (탑학원 3~5시)
  - **일**: ⏱️ 20분 타이머 · 📐 수학 복습·오답 · 📖 국어 (탑학원 12~2시) · 🏛️ 한국사 30분
  - **항목 편집**: `+ 추가`(이름·예상 시간·넣을 요일), `✎`(이름·이모지·설명·시간·요일), `✕`(그 요일 목록에서만 삭제 — 다른 요일은 그대로), `기본 목록으로`(그 요일 목록만 기본값으로 복원, 체크 상태는 유지). 편집기에서 요일을 여러 개 골라 같은 항목을 여러 요일에 둘 수 있습니다.
- **모녀 피드백** — 아이 한마디 / 엄마(보호자) 피드백 입력, 자동 저장
- **3단계 로드맵** — 습관·속도 잡기 → 겨울방학 실전 속도 → 입학 직후 수행·동아리, 단계별 체크
- **지난 기록** — 최근 7일 달성률 막대와 지난 한마디·피드백 모아보기
- 상단 헤더: 오늘 날짜, 입학 D-Day, 오늘 달성률, 그 주 달성률(보고 있는 주에 맞춰 `이번 주`·`지난주`·`다음 주`), 연속 기록일

## 실시간 동기화 구조

- **서버**: Google Apps Script 웹 앱 하나. 구글 시트(`1Vign4OfF1pPHRDJFGcyuY0YbFYFDsXfVae133HbTbAQ`)의 숨김 시트 **`_동기화`** 에 A1에 메타(rev·updatedAt·청크 수), A2 이하에 상태 JSON을 45,000자 단위로 나눠 저장합니다(셀당 5만 자 제한 회피).
- **읽기(`doGet`)** — `?token=…` 을 확인하고 `{ ok, rev, updatedAt, state }`를 돌려줍니다.
- **쓰기(`doPost`)** — 본문은 `Content-Type: text/plain;charset=utf-8`로 보내 CORS preflight를 피합니다. `LockService`로 동시 쓰기를 막고, 내가 마지막으로 본 서버 버전(`baseUpdatedAt`)이 그 사이 바뀌었으면 저장하지 않고 `conflict: true`와 최신 상태를 돌려줍니다(클라이언트가 병합 후 `force`로 다시 올림).
- **웹앱 쪽** — 변경이 생기면 350ms 디바운스로 바로 POST, 화면이 보이는 동안 6초마다 GET으로 폴링하고 `focus`·`visibilitychange`·`online` 때 즉시 한 번 더 확인합니다. 받은 상태는 더 최근에 바뀐 쪽을 남기는 방식으로 병합합니다(계획은 요일별 `planTs`, 체크는 날짜별 `updated`, 한마디/피드백은 각각 `kidTs`/`momTs`, 로드맵은 `roadmapTs`).
- **입력 보호** — 한마디·피드백·항목 편집기처럼 타이핑 중인 칸은 다시 그릴 때 덮어쓰지 않습니다.
- **상태 표시** — 헤더 아래 `☁️` 칩: `연결 중…` → `실시간 동기화 중` / `저장 중…` / `방금 저장됨` / `오프라인 · 이 기기에 저장`. 누르면 즉시 동기화를 시도합니다.
- **전환기·고입 일정 시트 반영(보너스)** — 같은 구글 시트에 `전환기·고입 일정` 탭(11/16~1/8, 가정통신문 기준)이 있고, `주간 체크표` 오른쪽 `📅 학교 일정` 열과 `3단계 로드맵` 아래 `고입 일정` 줄에도 같은 내용을 짧게 적어 두었습니다. 웹앱 일정은 이 내용을 화면에 고정으로 담고 있어(시트 동기화 대상 아님) 시트를 고쳐도 화면 일정은 그대로입니다.
- **주간 체크표 반영(보너스)** — 같은 구글 시트의 `주간 체크표`(11/16~12/13)에도 그 날짜 행의 해당 과목 칸에 `O`, `아이 한마디`·`엄마 피드백` 열에 글이 함께 기록됩니다. 기존 서식·병합은 건드리지 않고 셀 값만 바꾸며, 손으로 적은 다른 글은 지우지 않습니다.
- **토큰** — 웹 앱 주소를 아는 사람이 아무렇게나 쓰지 못하도록 간단한 공유 토큰을 씁니다. 페이지 소스를 보면 토큰이 보이므로 강한 보안은 아니고, 주소와 토큰은 가족끼리만 다루세요.

## 참고

- 기록은 기기 브라우저와 구글 시트 양쪽에 저장됩니다. 구글 시트가 원본 격이라, 폰을 바꾸거나 브라우저 저장소를 지워도 다시 열면 서버에서 그대로 받아옵니다.
- 알림음은 브라우저 정책상 사용자가 화면을 한 번 이상 터치한 뒤에 재생됩니다. 시작 버튼을 누를 때 오디오를 미리 깨워 두므로 타이머 종료 시에는 그냥 울립니다. 폰이 무음 모드이거나 볼륨이 0이면 소리는 나지 않으니, 시작 전 `🔔 소리 테스트`로 확인하세요.
- 주소 끝에 `?nosync=1`을 붙이면 **확인 모드**로 열립니다. 화면·타이머를 연습해 볼 수 있고 저장소·구글 시트는 건드리지 않습니다(알림 칩이 `☁️ 확인 모드 (저장 안 함)`으로 표시). 실제 기록을 건드리지 않고 시험할 때 씁니다.
- 저장 키는 `g1-planner:v3`입니다(요일별 계획 + 날짜별 체크). 예전 저장값(`g1-planner:v2`·`v1`)으로 이미 쓰던 기기는 처음 열 때 요일별 계획으로 한 번 옮겨지고, 그때까지의 **체크 상태·한마디·피드백·로드맵은 그대로 유지**됩니다. 사용자가 직접 만든 항목은 그 항목이 있던 요일에 남습니다. 옛 저장값은 지우지 않고 그대로 둡니다.
- 화면 접힘 상태는 기기에만 저장되고 구글 시트 동기화와는 상관없습니다(학원 일정 카드 `g1-planner:academy-open`, 전환기·고입 일정 카드 `g1-planner:sched-open`).

## 배포 방법 (수정할 때)

이 저장소는 GitHub Pages를 **`gh-pages` 브랜치 루트**에서 배포합니다. (Pages 소스 설정은 저장소 Settings → Pages에서 확인)
고칠 때는 `main`에 커밋한 뒤 **두 브랜치 모두**에 push해야 사이트에 반영됩니다.

```
git add -A && git commit -m "수정 내용"
git push origin main
git push origin main:gh-pages   # 이 줄이 있어야 사이트가 갱신됩니다
```

- 한 파일 앱이라 서버·빌드 과정이 없습니다. push 후 30초~1분이면 반영됩니다.
- Pages 소스를 `main` 브랜치로 바꾸고 싶다면 저장소 주인 계정으로 Settings → Pages에서 Branch를 `main` / `(root)`로 지정하면 됩니다.
