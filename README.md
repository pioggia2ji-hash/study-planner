# 고1 1등급 학습 플래너

중3 겨울 ~ 고1 입학 직후까지 쓰는 **모바일 학습 플래너**입니다.
서버 없이 `index.html` 한 파일로 동작하고, 기록은 각자의 휴대폰 브라우저(localStorage)에만 저장됩니다.

## 기능

- **집중 타이머** — 20/30/40/60분 프리셋(기본 20분), 시작·일시정지·리셋, 원형 진행 표시, 완료 시 부드러운 알림음(Web Audio)과 축하 효과. 프리셋을 바꾸면 타이머 표시·남은 시간·리셋 기준이 그 분으로 바로 바뀝니다(실행 중이면 일시정지 후 새 시간으로 리셋).
- **이번 주 학원 일정 카드** — 화·목(수학 17:00~20:00), 토(수학 12:00~15:00 · 국어 15:00~17:00), 일(국어 12:00~14:00)을 요일별로 보여주고 오늘 줄을 강조
- **오늘의 학습 체크리스트** — 학원 시간표·교재에 맞춘 기본 6개 항목, 체크하면 자동 저장
  - 항목마다 **예상 시간**과 **추천 요일**(예: 월·수·금) 표시, 오늘 요일에 맞는 항목에는 `오늘 추천` 표시와 안내 문구
    - ⏱️ 20분 타이머 켜고 시작하기 (매일)
    - 📐 수학 · 공통수학1 + 마플 순열·조합 (월·수·금·일 40분 / 화·목·토 학원 날은 오답 20분만)
    - 📖 국어 · 고전운문 + 비문학 1지문 (월~금 20분)
    - 🔤 영어 · 문법 약점 보완 + 고1 모의고사 (월·수·금 30분)
    - 🔬 과학 · EBS 통합과학1 인강 (월·수 각 35분)
    - 🏛️ 한국사 · 주 1회 흐름 잡기 (일 30분)
  - **항목 편집**: `+ 추가`로 새 할 일(이름·예상 시간) 추가, `✎`로 이름·이모지·설명·시간 수정, `✕`로 삭제, `기본 목록으로`로 복원
- **모녀 피드백** — 아이 한마디 / 엄마(보호자) 피드백 입력, 자동 저장
- **공유** (서버 없이 두 대의 폰에서 주고받기)
  - `카톡 공유용 요약 복사` — 날짜, ✅/⬜ 항목, 한마디·피드백, 달성률을 텍스트로 복사
  - `현재 상태 링크로 공유` — 현재 체크 상태·메모·편집한 항목 목록을 URL 해시(`#data=...`, Base64URL)에 담아 링크 복사. 링크를 연 사람의 화면에 그 날짜 기록이 그대로 불러와지고 저장됩니다.
- **3단계 로드맵** — 습관·속도 잡기 → 겨울방학 실전 속도 → 입학 직후 수행·동아리, 단계별 체크
- **지난 기록** — 최근 7일 달성률 막대와 지난 한마디·피드백 모아보기
- 상단 헤더: 오늘 날짜, 입학 D-Day, 오늘 달성률, 이번 주 달성률, 연속 기록일

## 사용법

1. 휴대폰 브라우저에서 아래 주소를 엽니다.
   `https://pioggia2ji-hash.github.io/study-planner/`
2. 홈 화면에 추가하면 앱처럼 열 수 있습니다(사파리: 공유 → 홈 화면에 추가 / 크롬: ⋮ → 홈 화면에 추가).
3. 아이 폰과 엄마 폰에서 각각 열고, 하루 끝에 `현재 상태 링크로 공유`로 서로 기록을 주고받습니다.

## 참고

- 공유 링크에는 그날의 체크·메모 내용이 그대로 담깁니다. **링크를 아는 사람은 내용을 볼 수 있으니** 가족끼리만 주고받으세요.
- 기록은 기기별로 저장됩니다. 다른 기기 기록은 공유 링크로만 넘어옵니다.
- 알림음은 브라우저 정책상 화면에서 한 번 이상 터치한 뒤에 재생됩니다.
- 저장 키는 `g1-planner:v2`입니다. 예전 목록(`g1-planner:v1`)으로 이미 쓰던 기기는 처음 열 때 원래 목록이 새 학원 맞춤 목록으로 한 번 바뀌고(체크·한마디·피드백은 유지), 그날 목록을 직접 고쳤다면 `기본 목록으로`를 눌러 새 기본값을 적용할 수 있습니다.

## 배포 방법 (수정할 때)

이 저장소는 GitHub Pages를 **`gh-pages` 브랜치 루트**에서 배포합니다. (Pages 소스 설정은 저장소 Settings → Pages에서 확인)
고칠 때는 `main`에 커밋한 뒤 **두 브랜치 모두**에 push해야 사이트에 반영됩니다.

```
git add -A && git commit -m "수정 내용"
git push origin main
git push origin main:gh-pages   # 이 줄이 있어야 사이트가 갱신됩니다
```

- 한 파일 앱이라 서버·빌드 과정이 없습니다. push 후 30초~1분이면 반영됩니다.
- Pages 소스를 `main` 브랜치로 바꾸고 싶다면 저장소 주인 계정으로 Settings → Pages에서 Branch를 `main` / `(root)`로 지정하면 됩니다.
