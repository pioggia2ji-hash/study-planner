# 고1 1등급 학습 플래너

중3 겨울 ~ 고1 입학 직후까지 쓰는 **모바일 학습 플래너**입니다.
서버 없이 `index.html` 한 파일로 동작하고, 기록은 각자의 휴대폰 브라우저(localStorage)에만 저장됩니다.

## 기능

- **20분 집중 타이머** — 15/20/40분 프리셋, 시작·일시정지·리셋, 원형 진행 표시, 완료 시 부드러운 알림음(Web Audio)과 축하 효과
- **오늘의 학습 체크리스트** — 기본 5개 항목, 체크하면 자동 저장
  - **항목 편집**: `+ 추가`로 새 할 일(이름·예상 시간) 추가, `✎`로 이름·이모지·설명·시간 수정, `✕`로 삭제, `기본 목록으로`로 복원
- **모녀 피드백** — 아이 한마디 / 엄마(보호자) 피드백 입력, 자동 저장
- **공유** (서버 없이 두 대의 폰에서 주고받기)
  - `카톡 공유용 요약 복사` — 날짜, ✅/⬜ 항목, 한마디·피드백, 달성률을 텍스트로 복사
  - `현재 상태 링크로 공유` — 현재 체크 상태·메모·편집한 항목 목록을 URL 해시(`#data=...`, Base64URL)에 담아 링크 복사. 링크를 연 사람의 화면에 그 날짜 기록이 그대로 불러와지고 저장됩니다.
- **3단계 로드맵** — 습관·속도 잡기 → 겨울방학 실전 속도 → 입학 직후 수행·동아리, 단계별 체크
- **지난 기록** — 최근 7일 달성률 막대와 지난 한마디·피드백 모아보기
- 상단 헤더: 오늘 날짜, 입학 D-Day, 오늘 달성률, 이번 주 달성률, 연속 기록일

## 사용법

1. 휴대폰 브라우저에서 아래 주소를 엽니다.
   `https://pioggia2ji-hash.github.io/study-planner/`
2. 홈 화면에 추가하면 앱처럼 열 수 있습니다(사파리: 공유 → 홈 화면에 추가 / 크롬: ⋮ → 홈 화면에 추가).
3. 아이 폰과 엄마 폰에서 각각 열고, 하루 끝에 `현재 상태 링크로 공유`로 서로 기록을 주고받습니다.

## 참고

- 공유 링크에는 그날의 체크·메모 내용이 그대로 담깁니다. **링크를 아는 사람은 내용을 볼 수 있으니** 가족끼리만 주고받으세요.
- 기록은 기기별로 저장됩니다. 다른 기기 기록은 공유 링크로만 넘어옵니다.
- 알림음은 브라우저 정책상 화면에서 한 번 이상 터치한 뒤에 재생됩니다.
